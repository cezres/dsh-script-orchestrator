# 27: 通过 cron 编排按计划执行

**What to build:** 用户通过对话创建带 IANA 时区的五位 cron 编排，系统按表达式自动执行，并在面板显示下次时刻与 run 历史；每日/每周引导只生成 cron，不增加触发类型。

**Blocked by:** 26 — 自动执行 every 编排并查看脚本结果

**Status:** claimed

- [ ] 创建时只接受契约规定的五位 cron 子集和显式 IANA 时区，非法字段、宏、秒字段及过密规则返回准确的 `script_input_invalid`。
- [ ] `nextOccurrence` 严格大于 `fromMs`，五年窗口内无解有界返回并在创建/更新时拒绝；运行期意外无解转为 `ended`。
- [ ] cron 编排能经既有 runner 自动执行并持久化 run，面板正确显示表达式、时区、下次时刻和脚本结果。
- [ ] DST 春季不存在的本地时间跳过，秋季重复时刻只取较早瞬时；每日/每周对话预设与生成 cron 使用同一时区，持久化 kind 仍为 `cron`。
- [ ] 重启保留未来计划，停机多次错过合并为最近一次 run，暂停期间不补跑；被合并的中间触发不生成记录。
- [ ] 测试覆盖纯函数、时区/DST、有界无解、自动执行、重启错过和面板回读，不引入 RRULE、`at` 或 `after`。
